# Synthetic MSIClust Example

This folder contains a reproducible synthetic MSI dataset for the MSIClust
vignette. The imzML/ibd pair is generated by
`generate_synthetic_msiclust_imzml.R`.

The data are artificial and should be used only as a workflow example. The
`synthetic_region` values in `synthetic_msiclust_design.csv` document the
simulated spatial pattern; MSIClust does not use those labels.

Files:

- `synthetic_msiclust.imzML`
- `synthetic_msiclust.ibd`
- `synthetic_msiclust_design.csv`
- `synthetic_msiclust_summary.txt`
- `generate_synthetic_msiclust_imzml.R`
